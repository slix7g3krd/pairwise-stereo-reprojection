# pairwise-stereo-reprojection

VR 转头时画面边缘露出一条黑边，late-latching 只补了旋转没补平移，快速侧移时视差对不上；重投影用的深度是上一帧的，角色挥手后手臂边缘被拉成橡皮；去遮挡区域没有回退，转头后新露出的画面采样到旧像素；畸变参数按单眼写死，IPD 调整后桶形畸变中心偏移；运动矢量只对不透明物体有效，透明粒子的重投影方向全错；注视点渲染的边缘区域分辨率低，重投影后低分辨率块跟着头动；帧节奏不稳，合成线程等不到新姿态就用旧姿态，画面顿一下；异步时间扭曲与异步空间扭曲同时开启，二者对同一像素重复位移；双目渲染共用一张重投影缓冲，左右眼深度不同导致边缘撕裂；预测姿态用固定 16ms 提前量，高刷新率设备上过度预测。render/stereo_reprojection.py 是核心，tests/test_stereo_reprojection.py 15个红。要修的是：旋转平移都补；深度按时间对齐；去遮挡回退；畸变按眼更新；透明单独矢量；注视区保边；合成用最新姿态；两种扭曲分工；双眼独立缓冲；预测按实际帧时长。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
